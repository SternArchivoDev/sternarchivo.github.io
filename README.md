Neovim Configuration Generator — Core EngineA high-performance, modular core written in Rust designed to programmatically generate, deploy, and manage Neovim configurations.🏗️ Core ArchitectureThe engine is built around a clean separation of concerns, dividing execution logic into distinct modules:main.rs (CLI & Entry Point): Powered by clap, it parses command-line flags (--deploy, --output, --run, --dry-run) and handles execution flow or initiates the HTTP daemon.generator.rs (Generation Pipeline): Manages temporary directory workspaces, assembles configuration skeletons (including init.lua and user modules), and handles target directory deployment or atomic overwrites.server.rs (HTTP Daemon): Built with hyper and tokio, exposing an asynchronous REST endpoint (POST /generate) to trigger remote configuration building via JSON payloads.config.rs & types.rs (Data & Constants): Defines shared domain models, package manager variants (lazy, packer, minimal, other), code snippets, and serialization structures.⚙️ Execution FlowInput Reception: The program accepts parameters either via CLI arguments or an incoming HTTP JSON request (GenerateRequestJson).Skeleton Synthesis: A temporary directory structure is populated with base options, bootstrap scripts for the chosen package manager, and custom user modules.Target Deployment: Depending on user directives, the generated configuration is:Deployed directly to the standard XDG_CONFIG_HOME path.Exported to a custom output directory.Executed on-the-fly by spawning a managed Neovim instance.
